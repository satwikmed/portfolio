# Satwik Medipalli — Portfolio

Mission Control–themed portfolio site built with Next.js, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub and connect to [Vercel](https://vercel.com) for one-click deployment.

## Structure

- `src/lib/data.ts` — all content (projects, experience, skills)
- `src/components/` — UI sections
- Dark "Mission Control" theme with cyan accent

## Customize

Edit `src/lib/data.ts` to update projects, experience, and contact info. Add project screenshots by dropping images into `public/` and referencing them in the project cards.
